<objective>
Swap the Postgres image to `pgvector/pgvector:0.8.6-pg18-trixie` (PGV-01) and install the `vector` extension at the shared level via a versioned core migration (PGV-02).

Purpose: Without the extension, no tenant `vector(1536)` column can exist. The image tag is pinned ≥0.8.2 (CVE-2026-3172 fix, per RESEARCH). The extension installs once per database into the first schema of the search_path — the core migration runs before school migrations, so it lands in `public` and every tenant schema can then use `public.vector`. Tenant DDL in plan 03 depends on this being true.
Output: Running pgvector-backed Postgres with `vector` in `pg_extension`, plus an idempotent core migration.
</objective>
