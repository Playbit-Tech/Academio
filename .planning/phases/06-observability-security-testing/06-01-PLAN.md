  <name>Task 1: Extend Prometheus metrics registry</name>
  <files>backend/internal/ai/metrics.go</files>
  <action>
    Extend the existing promauto registry in backend/internal/ai/metrics.go (do NOT create a second registry, do NOT duplicate existing families AIRequestsTotal, AIRequestDurationSeconds, AITokensTotal, AICostTotal, AIErrorsTotal).

    Add these new metric families using promauto.NewCounterVec / promauto.NewHistogramVec:

    1. AICacheHitsTotal = promauto.NewCounterVec(prometheus.CounterOpts{Name: "ai_cache_hits_total", Help: "AI cache hits vs misses"}, []string{"hit"}) — label "hit" with values "hit"|"miss".
    2. AIFallbackTotal = promauto.NewCounterVec(prometheus.CounterOpts{Name: "ai_fallback_total", Help: "AI provider failovers"}, []string{"from_provider", "to_provider"}) — from/to provider names.
    3. AICostPerTask = promauto.NewHistogramVec(prometheus.HistogramOpts{Name: "ai_cost_per_task_usd", Help: "Cost per successful AI task in USD", Buckets: []float64{0.001, 0.005, 0.01, 0.05, 0.1, 0.5, 1, 5}}, []string{"provider"}) — observe the cost_cents/100 value.
    4. AIQuotaRejectionsTotal = promauto.NewCounterVec(prometheus.CounterOpts{Name: "ai_quota_rejections_total", Help: "AI quota/rate-limit rejections"}, []string{"school_id"}) — increment in the orchestrator when CheckQuota returns ErrQuotaExceeded/ErrRequestCostExceeded.

    Each new family must export a comment line matching golint format (name starts with the metric name). Keep label cardinality bounded: provider labels must be from the known ProviderType enumerations (ProviderGemini, ProviderOpenAI, python:anthropic, python:deepseek, python:openrouter, python:azure-openai, python:ollama).

    Do NOT touch the existing 5 families or their registration.
  </action>
