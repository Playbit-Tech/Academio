<threat_model>
- Log disclosure of PII: any log call that would include document/prompt text MUST use MaskContent (D-04). No raw content in Go or Python logs.
- Secret at rest: AI provider keys and tokens must be encrypted with AES-256-GCM before DB write; never logged.
- Cross-tenant leak: `^school_\d+$` schema validation must have no fallback path (D-06); a malformed schema_name must 400, never silently default.
- Audit bypass: every AI mutation must emit a B11 audit event with SchoolID, UserID, Action, ResourceType, RequestID.
</threat_model>

  <name>Task 1: PII masking helpers</name>
  <files>backend/internal/security/pii.go, backend/internal/security/pii_test.go</files>
  <action>
    Create backend/internal/security/pii.go (new package "security" under backend/internal) with:

    - `func MaskContent(content string) string` — returns a redaction string "{len: N, sha256: <hex>}" where N = len(content) and hex = sha256 hex digest of the content. NEVER returns the content itself.
    - `func MaskContentSize(content string) string` — returns "{size: N}" only (used where even the hash is unnecessary).
    - `func RedactErrorMessage(msg string) string` — returns a safe error message: replaces any occurrence of a content-like payload (long strings > 100 chars or JSON-looking payloads) with MaskContent; for simple messages strips nothing but guarantees the return does not contain raw document/prompt text — implement conservatively: if the message is longer than 100 chars, return MaskContent(msg), else return the message unchanged.

    Write backend/internal/security/pii_test.go with tests:
    - TestMaskContent_Redacts: MaskContent("hello world") != "hello world", contains "sha256", and does not contain "hello world".
    - TestMaskContent_Deterministic: same input twice → same output.
    - TestRedactErrorMessage_LongContent: RedactErrorMessage(strings.Repeat("a", 200)) does not contain the 200-char content, contains "sha256".

    Follow B1 (no silent error discards — use crypto/sha256 directly, no error path). Package comment on pii.go.
